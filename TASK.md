# Задание. 
Необходимо реализовать web-приложение для работы с виртуальной машиной:
1. Подготовить скрипт для создания образа виртуальной машины на базе Debian 13 (Trixie) (https://cloud.debian.org/images/cloud/trixie/20261001-2618/) образ должен поддерживать ssh-подключение
2. Реализовать backend на python, который позволяет через QMP (https://www.qemu.org/docs/master/interop/qemu-qmp-ref.html) протокол запускать управлять виртуальной машиной QEMU (ver. 11.0.5) для подготовленного образа из пункта 
- реализовать запуск
- реализовать перезагрузку
- реализовать остановку
- реализовать подключение к serial port
- реализовать подключение по ssh к виртуальной машине
3. Реализовать frontend с web-интерфейсом на react (JavaScript), который содержит:
- кнопки включения 
- перезагрузки
- остановки виртуальной машины
- а как же позволяет создать виртуальную консоль (терминал).
### Требования к выполнению задания
frontend и backend должны разворачиваться с помощью docker compose
необходимо создать свой репозиторий для данного задания. Репозиторий должен содержать файлы исходного кода, dockerfile, скрипты для сборки и запуска задания и инструкцию для запуска и сборки
репозиторий должен содержать инструкцию для развертывания сервиса, а также инструкцию по использованию описанной функциональности
